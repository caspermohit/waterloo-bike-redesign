# Photographic component assembly — version 8

The exploded and assembled bicycle now uses the same seven complete photographic-style images. No illustrated components or final photo swap remain. The atlas was generated with the built-in image-generation tool, using the original Marin product photograph as a visual reference. It is a reconstructed educational depiction, not an exact product specification photograph.

The tyre, rim and spoke systems are complete in both wheels. The drivetrain is one continuous cassette–chain–chainring assembly. Component placements use measured rear hub, front hub, bottom bracket, seat collar and head-tube mounting coordinates. Each source region contains a whole component; none is cut out by subtracting a neighbouring component.

Files:
- dist/assets/bicycle-photo-parts-v8.png — alpha-transparent photographic-style component atlas.
- dist/realistic-bicycle.js — atlas region placement.
- dist/bicycle-assembly.js — scroll, arrows, captions and controls.
- tools/photo-parts-v8.json — source regions, transforms and mechanical mounts.
- tools/place-photo-parts.py — standard-library placement generator; run from any directory.

Validation: desktop assembly poses and independent 390px mobile checks; seven image components present; no final-image replacement; no horizontal overflow. Viewed complete and intermediate poses, including the fork-to-hub and frame-to-drivetrain junctions.

Image-generation prompt brief: transparent 3×3 atlas; seven complete separate photographic objects matching the navy hardtail reference; consistent perpendicular right-side camera; rear wheel, front wheel, bare frame, fork angled as mounted, saddle and seatpost, handlebar and controls, and one continuous drivetrain; no text, no backgrounds, no missing/occluded surfaces. The exact generated asset is retained alongside placement metadata for reproducibility of the website.
